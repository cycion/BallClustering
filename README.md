## Introduction
This repository implements experimental ball clustering using DBSCAN

[teamcode/algorithm](TeamCode/src/main/java/org/firstinspires/ftc/teamcode) contains several mathematical
algorithm used for processing

[teamcode/config](TeamCode/src/main/java/org/firstinspires/ftc/teamcode) contains configuration files

[teamcode/structure](TeamCode/src/main/java/org/firstinspires/ftc/teamcode) contains data structures and classes used to process and store data

[teamcode/pedro](TeamCode/src/main/java/org/firstinspires/ftc/teamcode/pedro) contains Pedro Pathing
